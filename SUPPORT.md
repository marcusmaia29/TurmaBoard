# Support

TurmaBoard is maintained by volunteers and does not provide a guaranteed
response time.

Before asking for help:

1. Read the [README](./README.md) and the relevant technical documentation.
2. Search [existing issues](https://github.com/marcusmaia29/TurmaBoard/issues).
3. Run `npm run check` and capture the complete error output.

Use the repository's question issue template for setup, development, and usage
questions. Include your operating system, Node.js version, relevant commands,
and a minimal reproduction when possible.

Use the bug report template for reproducible defects and the feature request
template for product proposals. Report security issues privately according to
[SECURITY.md](./SECURITY.md).
